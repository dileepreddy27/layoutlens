# Data and dependency provenance

`fixtures/statement.pdf`, `fixtures/receipt.png`, and their expected values are original synthetic examples generated by `docs/generate_fixtures.py`. They contain no real customer records and are covered by this repository's MIT license. No external document corpus, model weights, fonts, credentials, or user documents are redistributed.

The generator uses a PDF standard font name and Pillow's bundled default font through its public API. Dependency licenses remain their own: pdfplumber and pandas (MIT/BSD), Pillow (HPND), Tesseract (Apache-2.0), Transformers (Apache-2.0), PyTorch (BSD-style), boto3 (Apache-2.0). Transitive components have separate licenses. Review installed distributions and the chosen checkpoint's model card before redistribution. LayoutLM weights are user-supplied and not included.
